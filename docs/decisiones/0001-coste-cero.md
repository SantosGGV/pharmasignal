# 0001 · Coste cero

- Fecha: 2026-10-18 · Tarea: hoja de ruta · Estado: aceptada

## Contexto
PharmaSignal es un proyecto personal sin financiación: cualquier coste recurrente compromete su continuidad.

## Opciones
- Servicios gestionados de pago: servidor, API de consulta, LLM por API.
- Solo software libre, datos públicos y alojamiento gratuito.

## Decisión
Solo software libre, datos públicos y alojamiento gratuito. Nada de APIs, tokens ni servicios de pago; solo se paga algo si es imprescindible y no hay alternativa gratuita.

## Consecuencias
La consulta se hace en el navegador (DuckDB-WASM) y la web se publica en GitHub Pages. Los LLM, en local. ATC con RxClass. MedDRA solo con suscripción gratuita.
