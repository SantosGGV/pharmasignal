## Por qué
Se eligió la opción A del [ADR 0021](../decisiones/0021-historial-sin-venv.md): reescribir con filter-repo y push forzado explícito.

- Alternativa B, `.gitleaksignore` con las 2 huellas: descartada. Termina con código 0, pero no cumple «sin rutas personales» ni «sin `.pyc`».
- Alternativa C, reescribir solo `main`: descartada. `v1.0-tfb` seguiría con todo el `.venv` alcanzable.
- No se pide a Soporte de GitHub la purga de los commits viejos. No había secretos reales. Los commits viejos siguen accesibles por SHA un tiempo.
- El mirror de copia no se sube a ningún sitio. Se borra el 26/11/2026.
